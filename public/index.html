    Как это устроено

    Это портфолио-проект. Витрина, сервер и база — три отдельных слоя, которые общаются через REST API. Нажмите «API» в правом нижнем углу: там видно каждый запрос этой страницы и ответ сервера.

    Фронтенд

    HTML, CSS и JavaScript без фреймворков. ES-модули, корзина в localStorage, обложки и пластинки нарисованы на CSS.

    public/index.html, public/js/shop.js

    Бэкенд

    Node.js и Express. Валидация, транзакции при оформлении заказа, JWT-авторизация админки, лимит попыток входа.

    server/routes/public.js, server/routes/admin.js

    База данных

    SQLite через встроенный модуль node:sqlite. Четыре таблицы, внешние ключи, агрегаты и рекурсивный CTE для графика выручки.

    server/db.js
